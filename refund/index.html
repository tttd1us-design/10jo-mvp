1. 환불 원칙

10조 스튜디오의 도구는 결제 전에 무료로 충분히 사용해 볼 수 있습니다. 도구의 기능과 결과물을 확인한 뒤 결제하시므로, 결제 후에는 원칙적으로 환불이 어렵습니다.

2. 환불 가능한 경우

  • 결제가 중복으로 이루어진 경우
  • 결제 후 7일 이내이며, 유료 기능을 전혀 사용하지 않은 경우
  • 도구의 오류로 결과물을 받지 못한 경우

3. 환불 절차

이메일(10jo.studio@gmail.com)로 결제 일시, 결제 수단, 사유를 보내주시면 확인 후 3영업일 이내에 처리합니다.

4. 환불 불가 사유

  • 유료 기능을 이미 사용한 경우
  • 결과물을 다운로드한 경우
  • 단순 변심 (무료 체험으로 사전 확인이 가능하므로)
